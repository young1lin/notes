父亲这个角色，就是个失败的塑造，在主角陷入人生低谷时，不但没有帮助儿子，还冷嘲热讽，我知道是为了构建冲突，让场景戏剧化。还有配偶，房子是底线，把房子看得比一切都重要，后面虽然有所转变，但是，牛马始终是牛马。

而且为了戏剧化彰显，晚上写代码，主要用 Java，但实际上写的是 Python 代码。小程序呢，其实是 JavaScript 代码写的，和写的有出入。并且除了古早的汇编程序员，很少人会用 DOS 界面写代码。

如何实现路路通，没有具体的描述，只是一笔带过，一个好的故事不能让无关紧要内容占据故事的大部分篇幅。但是，这是故事的关键转折点，就像以前幕布后从天而降的神仙一样，突然就解决一切难题，这不是一个好故事该有的。

角色塑造为了惨而惨，**没有足够的动机支撑人物的性格转变**，也没有人物弧光，看不见主角在经历了一系列的事情后，成长了什么，改变了什么，但是又好像改变了什么，如变。

追逐单王的蒙太奇，怎么说呢，一般，很不如《寄生虫》那一段下大暴雨往下走的剪辑，后者每一帧都是有很大信息量的。
