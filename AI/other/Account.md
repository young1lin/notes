# 中转站

就推荐这些，其他的基本不可靠。要么不走缓存，不走缓存价格算，要么中转站本身的号容易被封号，导致你使用不稳定。

下面所有的 AI 都可以用中转站解决，中转站便宜，但是你的数据会被窃取，被中转站拦截，可能会被拿去卖数据。



中转站优势

1. 不用担心被封号

2. 便宜（便宜容易给你塞劣质 Token 或者偷你数据）



中转站劣势

1. 你不知道你用的模型是否是真的模型，或者满血的模型，你可能用的是 GPT\-5 实际上给你用的是 GLM\-4 模型。你可能用的 Claude Opus 模型，但是实际上是 Copilot 套餐中的阉割后的 128K 上下文的模型；

2. 你的 Claude Code 或者 Codex 提示词和它们系统自带的提示词会冲突，因为它们要伪装是对应的客户端访问，例如 Antigravity；

3. 还有那种拼车购买的，额度是共享的，总会有人用的多，有人用的少，但是钱是付的一样的。例如五个人拼车 200$  一个月的 Claude Max 会员。额度比 Pro 多很多，四倍。因为这个是 Pro 额度的 20 倍，五个人分，就是四倍。但是总会有人用的多，用的少，你自己拼车就会有问题；

4. 你的数据一定会被拦截，具体会被卖，还是如何，看中转站的良心了；

5. **享受不到原网站的其他增值服务，例如你开通了 ChatGPT Plus 你可以用 Sora，你可以尽情使用 DeepResearch，Codex 和 ChatGPT  的额度是分开计算的，两个你可以尽情用。Claude 可以使用 Claude Code Web、Claude Desktop 的所有 Agent 服务（类似 OpenClaw 但是更全）、Claude Chrome Plugin、Claude APP 联动云服务，动动嘴就能开发，手机上就能指挥。**
